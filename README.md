"# DBZLSW" 

This project is no longer developed because I suck at coding. The code in this repo would have been a nightmare to untangle and rewrite, and I think the target platform was misguided on my part. 

However, if you are some wayward Dragon Ball fan who stumbled upon this project somehow, fear not. I'm developing a new version of it in Love2D. In addition, another team is working on their own remake and it looks like they are pretty far into it: (https://old.reddit.com/r/DBZ_LSW_FANGAME/wiki/index).

As of late September, I am working on the underlying engine for the map segments, and I'd like to expand on what was in the original games. I'm continuing to work on this at a steady pace. It's one of those things I've been wanting to do since about 2010, but had no time or coding experience to really get started. But now that I am pretty fluent in Lua and have code that I can stand to work with (along with a better understanding of good practices thanks to the patterns I observed when working in Godot), I'll have an easier time developing the really tough stuff that I could not do with the tightly coupled code I had before; it really was a nightmare, so I'm glad I decided to drop it and start over.

At some point, I will open a new repo for what I'm working on now.
